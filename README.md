# Codex Skills

Личные скиллы для Codex.

## Скиллы

| Скилл | Назначение |
| --- | --- |
| [product-team-creator](skills/product-team-creator/SKILL.md) | Создаёт или настраивает продуктовую команду: PO-чат, интервью, состав команды, разделы, взаимодействия и мониторинг. |
| [team-lead-settings](skills/team-lead-settings/SKILL.md) | Настраивает репозиторий и работу тимлида: исполнителей, изоляцию, параллельность, ревьюеров, коллбеки и архивацию. |

## Установка

Скопируйте нужную папку из `skills/` в `$CODEX_HOME/skills` (обычно `~/.codex/skills`), сохранив `SKILL.md`, `agents/` и `references/`. Если скилл уже установлен, сначала сохраните свои изменения. Для обнаружения новых скиллов может потребоваться новая сессия Codex.

## Зависимости

Оба скилла требуют `grilling`, `task-scope-and-spec`, `task-coordination-strategies` и `to-tickets`. `product-team-creator` также использует `team-lead-settings` из этого репозитория. Остальные зависимости не включены; порядок их проверки и установки описан в `references/dependency-installation.md` каждого скилла.

Для работы с чатами, разделами и таймерами нужны соответствующие возможности приложения Codex. Подробные правила и ограничения находятся в `SKILL.md` каждого скилла.
